## 🎯 What Is kopru?

kopru is a desktop application that puts your entire server management into one easy-to-use window. Imagine having a terminal, file manager, live performance monitors, Docker controls, and database tools all working together without needing to switch between different programs. That's exactly what kopru does, and it's all connected through a single secure SSH connection.

Think of it as your mission control for any computer you manage remotely. Whether you're checking server health, moving files, running commands, or managing containers and databases, kopru brings everything together in a clean, modern interface.

### 🖱️ First-Time Setup

When you first open kopru, you'll see a welcome screen. Don't worry - you don't need to be a technical expert to get started. The application will guide you through connecting to your server.

You'll need three pieces of information to connect:
- Your server's IP address or hostname
- Your SSH username (usually "root" or your user account name)
- Your SSH password or key file

If you're not sure what these are, check with your server provider or IT department - they can provide these details.

## ✨ Main Features

### 🖥️ Built-in Terminal

Forget opening a separate command prompt. kopru includes a full-featured terminal right in the app. You can run any command exactly as you would on the server directly. The terminal supports tabs, so you can work with multiple connections at once.

### 📁 File Manager (SFTP)

Move files between your computer and server with a familiar drag-and-drop interface. The built-in file manager makes uploading websites, downloading logs, or organizing server files as easy as working on your own desktop.

### 📊 Live Server Metrics

Watch your server's health in real-time. kopru displays CPU usage, memory consumption, disk space, and network activity with beautiful, easy-to-read graphs. Set up alerts to notify you when something needs attention.

### 🐳 Docker Management

If your server runs Docker containers, kopru provides a visual dashboard for everything container-related. Start, stop, restart, and monitor containers with a few clicks. See resource usage per container and view logs without typing a single command.

### 🗄️ PostgreSQL Database Tools

Manage your PostgreSQL databases through a friendly interface. Browse tables, run queries, back up data, and monitor query performance - all without leaving the kopru window.

### 🔐 Single Connection Power

What makes kopru special is that all these tools work over one secure SSH connection. You don't need to configure multiple ports, manage separate keys, or juggle different credentials. One connection, complete control.

## 🤔 Frequently Asked Questions

### Is kopru free to use?
Yes, kopru is completely free and open-source. You can download and use it without any cost or subscription.

### Do I need to install anything on my server?
No. kopru connects using standard SSH (Secure Shell), which is already built into virtually every server operating system. You don't need to install additional software on your server.

### Is my connection secure?
Absolutely. kopru uses industry-standard SSH encryption to keep your data safe. Your passwords and file transfers are protected from eavesdropping.

### Can I use kopru for multiple servers?
Yes. You can save multiple server profiles and switch between them quickly. Each server gets its own set of tabs and connections.

### What if I need help?
The kopru community is active and friendly. Check the repository page for documentation, issue reports, and discussion links.
